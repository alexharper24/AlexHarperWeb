Five hero treatments, built and running

Each stage below is the real header, the real photo, and the real stylesheet, with only the layout changed. Resize the window to see how each behaves on a phone. Nothing here is wired into the homepage. Where the supplied mockup had a problem I have built the fixed version and said so.

Full-bleed image with cream fade

Work neededNone. This is what ships today.
PhotoUsed as shot, full composition, never cropped.
ContrastNavy on cream, passes comfortably.
